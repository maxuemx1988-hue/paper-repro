# Domain pack 模板

仅补充领域知识，不覆盖通用协议。未验证的经验标明“待验证”。

每份 pack 必须在正文前给出下列头部，缺一即 `selfcheck.py` 失败：

```
pack_version: <整数，内容变更即递增>
scope_includes: <一句话：本包覆盖什么>
scope_excludes: <一句话：本包明确不覆盖什么>
verified_cases: <已通过该包验证的论文清单；无则写“暂无”>
```

`scope_excludes` 是硬约束：论文落入排除区时**不得**直接套用本包，必须走
`spec/domain_profile.md` 的“扩展”路径，并把新增定义登记为晋升候选。

## 0. 范围与来源
适用模型、工具栈、参考文献、验证过的案例及限制。与头部 `scope_*` 一致，不得矛盾。

## 1. observable_assembly
原始量到观测量的公式、指标、单位和简并。

## 2. trivial_limit
可计算退化极限；每条写成立条件、参考值和容差依据。

## 3. invariants
仅列严格关系或明确条件下的关系；区分恒等式、极限性质和经验现象。

## 4. ground_truth_source
参考数据的来源、定位、版本、条件、用途、提取方法、不确定度及调参披露；优先正文/表格/配套数值，图像提取仅作后备。官方运行可作实现对拍参考，不自动代表发表结果；独立模式要求先行基线。

## 5. convergence_knobs
区分物理参数和数值控制参数；列收敛实验和误差预算，不设全领域默认阈值。

## 6. failure_taxonomy
候选原因、症状、判别实验及适用条件；症状不是已证实的归因。

## 7. env_pins
实际版本、求解器、dtype 和运行时探测方法，不依赖改写第三方库的隐含补丁。
